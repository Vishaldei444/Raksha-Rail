# 🛡️ Raksha Rail - Mobile-Based Safety System

**Raksha Rail** is a front-end web platform designed for Indian Railways security teams (such as RPF) to monitor threats, narcotics, explosive traces, and live surveillance in real time.

---

## 🚀 Features

* **Authorized Access & Login:** Secure authentication interface tailored for officers and drivers.
* **Control Dashboard:** Centralized panel displaying overall security index, vapor sensor status, and quick risk actions.
* **Live Surveillance Feed:** Integrated camera viewer with frame capture and real-time detection bounding overlays.
* **GPS & Platform Tracking:** Live geolocation tracking and platform-specific location selection.
* **Responsive Layout:** Optimized UI design using modern CSS, flexible layouts, and responsive breakpoints.

---

## 🛠️ Built With

* **HTML5:** Semantic layout structure and multi-page routing.
* **CSS3:** Custom UI design, responsive grids, overlays, and animations.
* **JavaScript (Vanilla):** Live camera access via Web APIs (`getUserMedia`), HTML5 Geolocation API, dynamic DOM manipulation, and interactive modal dialogs.
